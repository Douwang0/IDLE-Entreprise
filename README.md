# IDLE-Entreprise

A Python-based enterprise simulation game developed as a collaborative learning project, combining structured backend systems with intentionally humorous gameplay.

## 📌 Overview
IDLE-Entreprise was created as a group project to explore the challenges of developing a larger-scale application in a team environment.

While the game mechanics are deliberately exaggerated and humorous, the project primarily served as a practical exercise in software engineering concepts such as object-oriented programming, modular design, and version control using Git.  
It provided an opportunity to experience collaborative development, code organization, and iterative improvement in a realistic workflow.

## 🛠️ Features
- Economic simulation (money, taxes, profit, quotas)
- Buy and sell items with dynamic pricing logic based on in-game conditions
- Passive income systems
- Event system impacting gameplay state
- Persistent high score storage
- Pause menu with live statistics
- Items with custom behaviors (e.g. prices adapting to the player’s state)
- Start and end screens

## 🏗️ Architecture
The project follows a modular design separating:
- Game logic
- Economic systems
- Event handling
- UI components
